The solver searches box pushes by room and reconstructs player walks between them.

    node main.ts

The Node 22 driver reads each level.txt from MAKEFUN_INPUT_DIR and writes solution.txt under MAKEFUN_OUTPUT_DIR. Contest defaults are /input and /output.
